# PlanForge

توليد مخططات سكنية بـCP-SAT، مُدقَّقة على أربع طبقات، مع سجل إثبات لكل
رقم كودي يُستخدم في الحكم.

## الحدود قبل أي شيء آخر

**١. الأرقام الكودية غير مُصدَّقة.** كل رقم في `codes/uk/` كُتب من
الذاكرة أو من العرف المهني، لا من نص رسمي مفتوح. المخرجات تُختم
`NOT FOR CONSTRUCTION` حتى يوقّع مهندس كل رقم استند إليه الحكم. الختم
لا يُرفع بعَلَم في سطر أوامر — يُرفع بالتوقيع.

**٢. أخطر ما في المشروع أرقام التجهيزات**، لا أرقام الكود العام: منها
تُستنبط الأبعاد الدنيا التي تُغذّي المُحلّل، فرقم خاطئ في حيّز استخدام
يشوّه كل مخطط مولَّد لا حكمًا واحدًا. راجع `provenance_fixtures.py` أولًا.

**٣. فضاء الحل محدود بشجرة قطع.** غرفة على شكل L حول أخرى، فناء داخلي،
مظروف متدرّج — خارج ما يمثّله المُحلّل. مقبول لسكن صفّي؛ غير مقبول لمبنى
معقّد.

**٤. لا موزّع تلقائي للغرف على الأدوار.** كل غرفة في متطلب متعدد الأدوار
تحمل `storey` صريحًا، و`FEAS-001` يرفض غير ذلك.

**٥. الخادم بلا مصادقة.** محلّي فقط. `--allow-public` يفتحه على الشبكة
كاملًا؛ لا تفعل ذلك بلا طبقة مصادقة أمامه.

**٦. الحالات المرجعية تركيبية.** تحرس من الانحدار ولا تصدّق رقمًا.

## البدء

```bash
pip install -e ".[server,dev]"
planforge check-brief --brief briefs/example.json
planforge run --brief briefs/example.json --out out --svg --json
```

تعذّر الحل؟ لا تخمّن:

```bash
planforge diagnose --brief briefs/example.json --fast
```

يُخرج القيد المُلزِم واقتراحًا عدديًا: «مجموع المستهدفات 92.4 م² ضد
مظروف 78.0 م² — اخفض 14.4 م²». التبليط تام، فالمجموع يساوي المظروف ولا
يقاربه.

## الطبقات الأربع

| الطبقة | القياس | ما تكشفه وحدها |
|---|---|---|
| الجدوى | حسابي، قبل التوليد | `FEAS-*` — متطلب مستحيل قبل إهدار عشرين ثانية |
| خطوط المراكز | مستطيلات المُحلّل | `GEO-*` `NDSS-*` `ADM-*` `ADB-*` `ADF-*` `ADK-*` |
| الأبعاد الصافية | بين أوجه الجدران | `DRW-*` — الأساس القانوني؛ مخطط جاز الأولى قد يسقط هنا |
| قابلية التأثيث | حزم CP-SAT | `FIX-*` — غرفة تجوز رقميًا ولا تستوعب طقمها |

## الحلقتان

1. أبعاد دنيا مستنبطة من التجهيزات → تُضيَّق قبل التوليد.
2. غرفة تعذّر تأثيثها → يُشدّ حدها ويُعاد التوليد.

**حلقة ثالثة أُسقطت.** كانت تضخّم مستهدفات المساحة لتعويض سماكة
الجدران، وهي عديمة الأثر: مجموع مساحات الغرف مقيَّد بالمظروف قيدًا
صلبًا، فضربُ كل المستهدفات في عامل واحد يزيح الانحرافات معًا ولا يغيّر
التوزيع. محلّها الآن قياسٌ وتبليغ: `planforge run` يطبع كل غرفة انكمشت
دون مستهدفها والرقم الذي يُكتب في المتطلب مكانه.

⚠ اكتب مستهدفاتك على خطوط المراكز مباشرةً إن أردت رقمًا صافيًا دقيقًا —
الانكماش المتوقع 5–15% تقريبًا، أو شغّل `run` مرة واقرأ الأرقام المقترحة.

## التصدير

- **SVG** — معاينة سريعة، ويُستخدمه المحرر لعرض حالة الغرف غير القابلة
  للتأثيث.
- **DXF** — المخرج القابل للتسليم: طبقات باصطلاح معروف، أبعاد
  `DIMENSION` حقيقية تتحدّث مع سحب الجدار، وفتحات مقطوعة من الجدران
  هندسيًا لا محجوبة بصريًا.
  المسميات العربية في DXF تعتمد على تشكيل برنامج العرض (AutoCAD يشكّل؛
  غيره قد لا يفعل) — استخدم `--latin-labels` لمخرج مضمون في كل عارض.

## مراجعة الأرقام

المسار العملي: وثيقة واحدة في جلسة واحدة، مرتَّبة بالخطر.

```bash
planforge codes worksheet -d "Approved Document B" --limit 25
# املأ verdict و clause_confirmed و reviewer
planforge codes import --file code_review.csv
planforge codes progress
```

قبل تطبيق أي تصحيح، قِس أثره:

```bash
planforge codes impact "uk.protected_stair_threshold" 4500
```

ثوابت محفوظة:
- الصفّ المحكوم عليه بالخطأ **لا يُوقَّع** — يخرج في ملف تصحيحات.
- ورقة صُدِّرت قبل تعديل رقم **تُرفض** — لا توقيع على قيمة لم يرَها المراجع.
- التوقيع مقفول بتلبيد القيمة: تغيّرت ⟹ بطل.

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | سليم |
| 1 | مخالفات |
| 2 | أرقام غير موقَّعة أو فجوة تغطية |
| 3 | تعذّر |
| 4 | خطأ استخدام |

`1` يقول «المخطط يخالف». `2` يقول «لا أعرف، لأن أرقامي غير مُصدَّقة».
خلطهما يجعل بوابة التسليم عقبةً تُتجاوَز.

## المحرر

```bash
planforge serve            # 127.0.0.1:8000
```

الغرف تُعرَّف بمعرّفات خطوط لا بأرقام، فتحريك خط يحرّك كل الغرف المرتبطة
به معًا: التراكب والفراغ مستحيلان بنيويًا، لا بالفحص بعد الحدث. وأي
تعديل يُدخل مخالفة جديدة يُرفض مع بيان ما كان سيُدخله.

## الاختبارات

```bash
pytest                       # كل شيء
pytest -m "not slow"         # بلا استدعاء المُحلّل
pytest tests/test_provenance.py   # تغطية سجل الإثبات
```

`test_provenance.py::test_no_coverage_gaps` أهمها: سقوطه يعني رقمًا
يُقرأ في حكمٍ بلا مسار للتوقيع.

## الحالات المرجعية: ما بقي

الحالة الوحيدة حاليًا (`gc01_bedroom_below_ndss.json`) **غير مضبوطة
بعد**: `expect_errors` كُتب من قراءة القواعد لا من تشغيلها فعليًا. شغّل
`pytest tests/test_golden.py` وصحّح القائمة بما يظهر — بعد التحقّق أن
كل معرّف ظهر لسببه الصحيح، لا بنسخ المخرج كما هو.

الأولوية التالية: حالات مرجعية حقيقية مأخوذة من مخطط مرّ على سلطة
رقابية فعلًا، لا حالات تركيبية إضافية.

## ما بقي بعد هذه الدفعة

1. **ضبط الحالات المرجعية بتشغيلها فعلًا** (أعلاه).
2. **مراجعة خريطة الاستناد (`codes/usage.py`) قاعدةً قاعدة.** أن تُحلّ
   أنماطها مضمون (يحرسه `test_usage_map.py`)؛ أن يكون إسنادها صحيحًا لا.
   كتلة اعتماد تقول «كل ما استند إليه موقَّع» بناءً على خريطة خاطئة
   أخطر من غيابها.
3. **توقيع الأرقام.** ابدأ بـ`uk.protected_stair_threshold` — خطؤه
   يقلب تصنيف المبنى كله — ثم حيّزات الاستخدام في
   `fix.catalogue[*].activity_*`.
4. **حالات مرجعية حقيقية** بدل التركيبية.
